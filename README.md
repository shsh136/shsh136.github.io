## Updating my resume (works from a phone)

All resume details live in one file: **[`_data/resume.yml`](_data/resume.yml)**.
Saving it rebuilds **both** the website and the PDF automatically in about 2 minutes.

1. Open **https://github.com/shsh136/shsh136.github.io/edit/main/_data/resume.yml** (bookmark it).
2. Edit the text. Use `**double stars**` for bold, and keep the indentation as it is.
3. Tap **Commit changes…** → **Commit changes**.
4. Check progress on the [Actions tab](https://github.com/shsh136/shsh136.github.io/actions). A green tick means it's live.

If a change has a mistake, the build fails, GitHub emails you, and the previous version stays online.
If the PDF grows past one page, the build shows a yellow warning. Shorten a bullet or two.

| File | What it is |
|---|---|
| `_data/resume.yml` | All resume content: the only file you normally edit |
| `index.html` | Website layout |
| `resume.html` | PDF layout (printed to `Shubhika_Shree_Resume.pdf` on each build) |
| `.github/workflows/deploy.yml` | Builds and publishes the site and PDF |
